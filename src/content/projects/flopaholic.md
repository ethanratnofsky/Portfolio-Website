Flopaholic is a React web application that allows users to simulate Texas
Hold'em poker hands and test their knowledge of hand rankings. The application
features a custom, random card generator and a custom algorithm for determining
the ranking of a given hand. It also includes many configurable settings for
the user to customize their experience.

A game version of the application is also in development, available at
https://ethanratnofsky.github.io/Flopaholic/#/game.
